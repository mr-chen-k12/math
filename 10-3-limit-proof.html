\(\displaystyle \lim_{x\to 2^-}\frac{1}{(x-2)^3} = -\infty\)

An \(M\)–\(\delta\) proof of an infinite limit, visualized step by step • October 3

1. What does “the limit is \(-\infty\)” mean?

We say \(\displaystyle\lim_{x\to 2^-} f(x) = -\infty\) when the following holds:

For every negative number \(M\) there exists a \(\delta > 0\) such that
\[x < 2 \quad\text{and}\quad 0 < |x-2| < \delta \quad\Longrightarrow\quad f(x) < M.\]

In plain words: no matter how far down you set the bar \(M\), the function dives below that bar whenever \(x\) gets close enough to 2 from the left. The proof below builds the \(\delta\) that works for any \(M\) you choose — and the interactive demo lets you test it.

    4. The complete formal proof

    Theorem. \(\displaystyle\lim_{x\to 2^-}\frac{1}{(x-2)^3} = -\infty\).

    Proof. Let \(M\) be any negative number. Choose \(\delta\) positive and equal to the minimum of \(1\) and \(\dfrac{1}{|M|}\). Assume \(x < 2\) and \(0 < |x-2| < \delta\). Then \(|x-2|^3 < \delta^3 \le \delta \le \dfrac{1}{|M|}\). Hence, \(\dfrac{1}{|x-2|^3} > |M| = -M\). But \((x-2)^3 < 0\). Therefore, \[\frac{1}{(x-2)^3} = -\frac{1}{|x-2|^3} < M.\] Since \(M\) was arbitrary, this holds for every negative \(M\), which is precisely the definition of the limit being \(-\infty\). ∎

    Each move in this proof is exactly what the sliders above let you test: the choice of \(\delta\), the cubing step (which is why \(\delta \le 1\) is needed), and the sign flip from \((x-2)^3 < 0\).

    5. So the (finite) limit does not exist

    “Equals \(-\infty\)” is the precise way of saying no finite number can be the limit. Here is why, by contradiction:

    Suppose, to the contrary, that \(\displaystyle\lim_{x\to 2^-}\frac{1}{(x-2)^3} = L\) for some finite number \(L\). Take \(\varepsilon = 1\) in the ordinary \(\varepsilon\)–\(\delta\) definition: there must be a \(\delta_1 > 0\) with \[|f(x) - L| < 1 \quad\text{hence}\quad f(x) > L - 1\] whenever \(x < 2\) and \(0 < |x-2| < \delta_1\). But \(M = -|L| - 2\) is a negative number, so the theorem above gives a \(\delta_2 > 0\) with \(f(x) < M\) whenever \(x < 2\) and \(0 < |x-2| < \delta_2\). For \(x\) satisfying both (take \(\delta = \min(\delta_1,\delta_2)\)), we would need \[L - 1 < f(x) < -|L| - 2 \le L - 2 < L - 1,\] an impossibility. Hence no finite \(L\) works — the finite limit does not exist, and we write the limit as \(-\infty\). ∎
